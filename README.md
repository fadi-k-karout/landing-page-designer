# Landing Page Designer

An AI agent skill for designing better landing pages.

It helps AI agents create clear, focused, and conversion-friendly landing pages for products, SaaS apps, services, and startups.

## What It Does

The skill helps with:

* Landing page structure
* Hero sections
* Headlines and value propositions
* Benefits and features
* Product showcases
* Social proof
* CTAs
* Objection handling
* Landing page reviews

It focuses on **clear messaging, good visual hierarchy, and one clear conversion goal**.

## When to Use It

Use this skill when you want an AI agent to:

* Create a landing page
* Improve an existing landing page
* Design a landing page structure
* Write landing page copy
* Review landing page UX
* Improve conversion-focused messaging

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/landing-page-designer.git
```

Then add `SKILL.md` to your AI agent's skills directory.

The repository contains only three files:

```text
landing-page-designer/
├── SKILL.md
├── README.md
└── LICENSE
```

## Example

Give your agent a product like:

```text
Build a landing page for an AI tool that turns
meeting recordings into project tasks.

Target users: startup teams.
Goal: get users to start a free trial.
```

The skill will help the agent structure the page around:

```text
Hero
↓
Problem & Solution
↓
Benefits
↓
Product Showcase
↓
Social Proof
↓
Objections
↓
Final CTA
```
